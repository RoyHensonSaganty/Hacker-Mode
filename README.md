# Hacker Mode

A simple interactive **Hacker Mode web experience** built with **React.js**.

The project features a dark hacker-themed interface with a **Matrix-style rain animation** and an interactive terminal-inspired design.

## Features

- Hacker-themed UI
- Terminal-inspired interface
- Matrix rain animation
- Interactive experience
- Dark-themed design

## Technologies Used

- React.js
- JavaScript
- CSS
- HTML5
- React Hooks
